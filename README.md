# VentureVelocity
Startup Performance & Benchmarking Platform

VentureVelocity helps startup founders measure their business potential, track progress, and discover growth opportunities. It also helps investors identify promising startups through performance metrics and benchmarks.

# Features
Potential Index: Measures a startup's market opportunity and business potential.
Progress Index: Tracks startup growth, milestones, and customer traction.
Startup Leaderboard: Compare startups by category and performance.
Growth Roadmap: Get actionable suggestions to improve startup performance.
Competitor Analysis: Compare startup features and business strategies.
Demo Mode: Explore sample startups and their performance scores.
Privacy Controls: Support private profiles and evidence-based evaluation.
🛠️ Tech Stack
React
TypeScript
Vite
Tailwind CSS (if configured)
Supabase and Google Gemini API (planned integrations, if not yet implemented)
# Getting Started

1. Clone the repository

bash
git clone YOUR_GITHUB_REPOSITORY_URL


2. Navigate to the project folder

bash
cd venture-velocity


3. Install dependencies

bash
npm install


4. Start the development server

bash
npm run dev


Open the local URL displayed in your terminal to explore the application.
